# 리본 제작 검증 순서

## 현재 배포

추가 천 제작은 중단했다. 이번 배포는 기존 리본 자산을 사용한 초기 표지·책장 개방 수정에 한정한다. 초기 표지 색상과 인계, 정상 개봉, 예외 종료, 두 디자인의 요구 너비를 검증하고 보호된 GitHub Actions 배포와 운영 canary로 마무리한다. 새 리본 제작을 이 배포의 선행 조건으로 다시 확대하지 않는다.

아래 순서는 향후 리본 자산 교체를 별도로 요청할 때 사용한다.

1. 리본 단독 주요 프레임과 저해상도 연속 샘플을 만든다. 형태의 연속성과 완전한 매듭 해제를 검증한다.
2. 통과한 동작에 최종 재질·조명을 적용하고 고정 캔버스의 투명 프레임과 매니페스트를 출력한다.
3. 공개 인트로에 연결하고 정상 재생, 새로고침, 건너뛰기, 실패, 시간 초과, 언마운트를 확인한다.
4. 두 변형의 요구 화면 너비, 키보드와 동작 줄이기 설정을 검사한다. 모바일 실기기 확인이 불가능하면 그 한계를 기록한다.
5. 기존 테스트·빌드와 독립 검토를 통과한 변경만 보호된 GitHub Actions 배포로 전달하고 프로덕션 canary로 종료한다.

검증 전 단계는 완료로 간주하지 않는다. 단독 샘플이 실패하면 공개 인트로 연결과 배포를 진행하지 않는다.
