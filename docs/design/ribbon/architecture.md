# 리본 제작 및 재생 구조

제작과 공개 실행을 분리한다. Blender의 고정된 장면에서 리본을 제작하고 투명 이미지로 출력하며, 브라우저는 출력 프레임만 그린다. Blender는 제작 도구이고 공개 앱의 의존성이 아니다.

- 제작 원본과 재현 명령은 `scripts/ribbon/`에서 관리한다. Blender 4.5 LTS 계열을 사용하며 실제 출력 버전과 소스 해시는 산출물에 기록한다.
- 공개 자산은 `public/assets/design/ribbon-sequence/`의 매니페스트와 같은 크기의 WebP 프레임이다. 리본과 띠를 함께 출력한다.
- 프레임 이름에는 파일 내용 해시를 포함하고 매니페스트는 HTTP 캐시를 재검증한다. 배포 경계에서 예전 매니페스트가 남더라도 새로운 동작의 프레임과 섞이지 않아야 한다. 준비할 수 없는 조합은 본문으로 넘어간다.
- `src/intro/`의 재생기가 프레임 준비, 재생, 리본 퇴장, 패널 개방, 종료를 관리한다. 패널 개방은 마지막 리본 프레임 이후에만 가능하다.
- 프레임 디코딩은 제한된 버퍼로 수행하고 취소 시 해제한다. 실패·시간 초과·언마운트에서 콜백과 스크롤 복원이 중복되지 않아야 한다.
- 초기 HTML의 표지는 메인 앱과 독립적으로 보인다. 공개 콘텐츠 준비 조건은 움직임의 시작을 결정하며, 인트로가 콘텐츠를 다시 가져오거나 공개 리비전을 바꾸지 않는다.

공개 API 변경은 없다. 원본 레퍼런스 영상과 로컬 검토 영상은 배포하지 않는다.

## 재제작 구조

초기 표지는 Vite의 개발·빌드 변환에서 같은 첫 프레임과 종이 자산을 HTML에 삽입한다. 작은 외부 스크립트가 공개 Pastel 여부, 준비 기한과 소비된 상태를 관리한다. 재생 준비 완료 뒤에는 초기 표지와 React의 첫 프레임을 같은 화면 갱신에서 교체한다. 초기 단계의 건너뛰기·실패·시간 초과는 앱에 전달되어 뒤늦은 재등장을 막는다.

준비 상한 5초는 초기 표시부터 계산한다. 준비 완료 이후의 풀림·종이 대기·개방은 별도의 제한된 재생 감시를 사용한다. 비활성 탭에서 시간이 흐른 만큼 동작을 건너뛰지 않는다. 모든 종료 경로는 요청, 이미지 버퍼, 스크롤 잠금을 해제한다.

스키마 2 자산에는 첫 표지 해시, 기준점, 해제 완료 프레임, 전체 하강 위치와 양쪽 종이 경로가 들어 있다. 기준점과 배율은 고정하고 완전 해제 이후의 전체 하강만 화면 높이에 맞춘다. 천 자체의 변형과 접촉은 오프라인 계산 결과에 남긴다.

종이의 가장자리 경로는 표면 운동과 구분한다. 사용자 추가 피드백에 따라 종이는 양쪽 바깥 접힘선을 축으로 앞으로 넘어간다. 기존 측정 곡선의 개방 비율을 `p`라고 할 때 직교 투영의 회전각 `acos(1-p)`로 같은 가장자리 경로를 만들 수 있다. CSS의 `rotateY`로 종이 면과 무늬를 함께 회전하고 좌우 조명 변화와 단면을 더한다. 이는 원본의 실제 카메라나 종이 곡률을 복원했다는 주장이 아니다. 원본에서 보이는 무늬 압축과 명암 변화를 재현하는 평면 회전 모델이며, 브라우저에서 천 계산이나 WebGL 장면을 실행하지 않는다.

처음 닫힌 각도는 0이고 초기 HTML과 재생기가 같은 종이 좌표·명암을 사용한다. 회전 중 실제 가장자리와 매니페스트 곡선이 지정한 위치의 차이를 390px 기준 1px 이내로 확인하고, 중간 프레임에서 무늬가 가로로 압축되는지 별도로 검사한다. 이 구현 오차는 원본 관찰값에 곡선을 맞출 때 발생하는 오차와 구분한다. 리본 퇴장 완료, 일시 정지, 건너뛰기와 본문 보존 조건은 그대로 적용한다.

닫힌 중앙 이음선은 개봉이 시작되는 첫 화면 갱신에서 제거한다. 종이가 벌어진 뒤 본문 위에 고정된 선을 남기지 않는다. 실제 곡선은 지정된 전체 시간보다 먼저 폭 0에 도달할 수 있으므로 종이 제어기의 종료는 진행률 1이 아니라 유효 경과시간 1400ms로 결정한다. 숨김 시간은 이 경과시간에 포함하지 않는다. 초기 HTML과 React는 같은 내장 종이 이미지 바이트를 사용하여 인계 시 추가 다운로드로 표면이 바뀌지 않게 한다.

스키마 1 판독은 기존 자산으로 새 표시·재생 구조를 검증하는 과도기 경로다. 스키마 2 검사 성공은 물리 풀림의 시각 승인과 다르다. 실제 새 자산이 단독 검증과 사용자 비교를 통과하기 전에는 운영 자산으로 교체하지 않는다.

## 천 계산의 검증 경계

기준 형상 설정값을 읽는 것만으로 실제 천 계산에 적용됐다고 판정하지 않는다. 제작에 쓰는 수정자 순서를 그대로 복제한 작은 실험에서 선택한 기준 형상의 길이와 계산된 길이를 비교한다. 모든 중간 프레임을 차례대로 평가하고, 선택하지 않은 대조군과 중력에 반응하는 대조군을 함께 확인한다. 프레임을 건너뛰어 평가한 캐시는 증거로 사용하지 않는다.

초기 형상의 면 교차와 접촉 여유를 따로 검사하고 기록한다. 정점을 공유하는 면의 연결 관계와 천의 서로 다른 구간 사이 접촉을 구분한다. BVH의 `epsilon`을 키운 뒤 겹침이 없다는 결과는 면 사이 최소 거리의 증거가 아니다. 가까운 면 후보의 점–삼각형 및 모서리–모서리 거리를 직접 계산한다. 충돌 계산의 여유 거리보다 가깝다는 사실과 실제 면 관통은 구분한다. 전자는 안정화 과정에서 확인할 위험이며, 임의 수치만으로 물리적으로 불가능하다고 판정하지 않는다. 첫 형상의 통과 역시 이후 풀림 성공을 보증하지 않는다.

초기 응력을 가라앉히는 준비 계산이 필요하면 자유 끝단만 제어하는 같은 천 계산을 연속 평가한다. 실제 안정된 묶인 프레임을 공개 F0와 초기 표지로 사용하며, 별도로 예쁜 정지 형상을 끼워 넣지 않는다. 원본 계산 프레임과 출력 프레임의 대응, 재료 표식, 길이·폭 변화, 면 교차와 종이 접촉을 함께 기록한다.

느슨한 통로를 조이는 준비 계산도 이 경계를 따른다. 내부 정점을 고정하거나 매듭을 축소하지 않고 반대쪽 끝단을 당겨, 고리가 유지된 채 실제 천이 조여지는지 확인한다. 충분히 조여졌다는 외형 판단과 관통·재료 변형 검사를 모두 통과한 상태만 이후 풀림의 첫 프레임 후보로 사용한다. 조임과 풀림 사이에 다른 형상을 끼워 넣거나 평평한 기준 형상을 새로 정의하지 않는다.

평가할 프레임 수와 제작한 동작의 길이를 분리한다. 초기 한 프레임만 검사하더라도 당김 키프레임을 F1로 옮기지 않는다. 원시 입력과 실제 F1의 전체 정점 차이, 끝단 제어 위치와 캐시 상태를 확인한 뒤에만 이후 변화를 천 계산의 결과로 해석한다.

원본 두 곡선은 재료 연결과 중앙 교차 순서의 참고 자료로 사용한다. 기존 애니메이션의 `progress=0`은 이미 고리 회전과 비대칭 변형이 적용된 형상이므로 원본과 같다고 간주하지 않는다. 새 초기 형상은 평평한 띠의 재료 길이를 유지하는 접힘으로 직접 제작할 수 있으며, 원본과 같은 매듭이라고 주장하려면 실제 재료 경로의 앞뒤 관계를 별도로 대조한다. 종이 뒤 연결부는 매듭 보호영역 밖에서 구성한다. 연결된 한 장이라는 사실이나 최종 교차 수 0만으로 풀릴 수 있는 매듭임을 판정하지 않는다.

재료의 폭 합계와 중심선 길이만 측정하지 않는다. 평평한 원본 격자에 대한 종방향·횡방향·대각선 길이 변화와 접촉 여유를 함께 기록한다. 묶인 형상을 기준 형상으로 재정의해 오차를 0으로 만드는 것은 재료 길이 보존의 증거가 아니다. 매듭 전체가 종이 앞으로 이동한 상태와 고리가 실제 통과해 풀린 상태도 구분한다.

초기 제작·천 계산·렌더링·검수에는 동일하게 명시한 삼각형 면 연결을 사용한다. 접혀서 한 평면에 있지 않은 사각형을 각 도구가 다르게 나누게 두지 않는다. `BVHTree.overlap`은 같은 평면에서 면적이 겹치는 삼각형도 누락하므로 이것만으로 후보가 모두 검출됐다고 판정하지 않는다. 좌표 경계 상자로 보수적인 후보를 만들고, 삼각형 내부를 가로지르는 교차, 같은 평면에서의 양의 겹침 면적, 경계 접촉, 수치적으로 보고된 분리를 구분한다. 정점을 공유하는 이웃 면도 되접히면 면적이 겹칠 수 있으므로 일괄 제외하지 않는다. 후보 검사 가속은 전수 대조와 실제 실패 면쌍의 재현으로 검증한다. 정점 사이를 직선으로 잇는 재료 추적선이 실제 접힌 면에서 벗어나지 않도록 내부 접힘선을 지나는 재료 좌표도 추적한다.

재료 경로의 국소 교차 수가 0이 된 것만으로 고리 통과를 판정하지 않는다. 교차점이 추적 구간의 시작·끝을 벗어났는지, 원래 고리 꼭대기의 재료가 실제로 통과했는지, 열린 경계가 벌어졌는지를 함께 확인한다. 중심선과 양쪽 가장자리를 추적하고, 비평면 통로에서 가상 면을 다르게 구성했을 때 판정이 갈리면 연결부까지 범위를 넓힌다. 전 프레임 결과를 집계하며, 일부 진행 표본이나 마지막 프레임만으로 관통 0을 주장하지 않는다.

저장된 천의 렌더러는 원본 장면의 F1을 먼저 평가하고 카메라·조명을 고정한다. 원본과 캐시의 첫 형상을 평가 결과로 대조하며, 출력마다 실제 최종 정점과 삼각형 연결을 다시 확인한다. 종이 뒤 리본은 실제 종이 면으로 차폐하고, 그림자는 해당 프레임의 천이 만드는 그림자 패스에서 계산한다. 그림자를 받는 종이 영역 밖으로 알파가 새거나 고정 그림자를 반복하는 결과는 채택하지 않는다.

완전 해제 뒤의 하강 분리는 원본 재료 면적을 기준으로 한 중심의 수직 이동을 사용한다. 그 이전 좌표와 이동량 0을 보존하고, 분리한 천과 이동량을 합친 좌표가 원본과 일치해야 한다. 종이 접촉이 남거나 경로가 상승하면 임의로 잘라 맞추지 않고 거부한다. 이 도구는 별도로 지정한 해제 시점을 검사할 뿐 매듭 해제를 자동 승인하지 않는다.

복잡한 매듭을 실패 원인 분석에 바로 사용하기 전에 길이가 보존된 단순 접힘의 자기 충돌 켜기·끄기 대조군으로 계산 설정을 확인한다. 한 고리가 고정 통로를 통과하는 별도 실험은 접촉 계산의 검증 자료다. 그 통로를 독립 물체로 만든 결과는 한 장의 리본이 풀렸다는 증거가 아니며, 최종 제작에서는 통로·고리·뒤 띠를 같은 재료에 포함해 다시 검증한다.

웹의 자동 검사는 첫 표시·위치·순서·자원 예산을 검증한다. 합성 스키마 2 입력이나 기존 스키마 1 자산의 기능 검사 결과로 실제 매듭 통과를 승인하지 않는다. 성능 검사는 여러 브라우저 검사 파일의 CPU 경쟁을 피하도록 순차 실행하고, 실패한 병렬 실행 기록도 보존한다. 이 조건은 iPhone Chrome 실기기 검증을 대신하지 않는다.
