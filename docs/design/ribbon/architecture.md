# 리본 제작 및 재생 구조

제작과 공개 실행을 분리한다. Blender의 고정된 장면에서 리본을 제작하고 투명 이미지로 출력하며, 브라우저는 출력 프레임만 그린다. Blender는 제작 도구이고 공개 앱의 의존성이 아니다.

- 제작 원본과 재현 명령은 `scripts/ribbon/`에서 관리한다. Blender 4.5 LTS 계열을 사용하며 실제 출력 버전과 소스 해시는 산출물에 기록한다.
- 공개 자산은 `public/assets/design/ribbon-sequence/`의 매니페스트와 같은 크기의 WebP 프레임이다. 리본과 띠를 함께 출력한다.
- 프레임 이름에는 파일 내용 해시를 포함하고 매니페스트는 HTTP 캐시를 재검증한다. 배포 경계에서 예전 매니페스트가 남더라도 새로운 동작의 프레임과 섞이지 않아야 한다. 준비할 수 없는 조합은 본문으로 넘어간다.
- `src/intro/`의 재생기가 프레임 준비, 재생, 리본 퇴장, 패널 개방, 종료를 관리한다. 패널 개방은 마지막 리본 프레임 이후에만 가능하다.
- 프레임 디코딩은 제한된 버퍼로 수행하고 취소 시 해제한다. 실패·시간 초과·언마운트에서 콜백과 스크롤 복원이 중복되지 않아야 한다.
- 기존 공개 콘텐츠 준비 조건이 인트로의 마운트를 결정한다. 인트로는 콘텐츠를 다시 가져오거나 공개 리비전을 바꾸지 않는다.

공개 API 변경은 없다. 원본 레퍼런스 영상과 로컬 검토 영상은 배포하지 않는다.
