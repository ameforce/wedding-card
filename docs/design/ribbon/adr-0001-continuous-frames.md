# ADR 0001: 하나의 리본 동작에서 출력한 연속 프레임

상태: 사용자 승인. 재생부 검증 통과, 3D 샘플 미통과로 공개 통합 보류.

기존 7장 포즈는 고리와 매듭 형태가 연속하지 않고 개별 크롭 때문에 표시 배율도 달라졌다. CSS 이동과 투명도 보정만으로 실제 풀림을 재현할 수 없었다.

고정 장면의 리본 원본에서 연속 동작을 제작하고 30fps 투명 프레임으로 출력한다. 브라우저에서는 같은 기준점으로 프레임을 교체하며, 리본이 사라진 뒤 종이를 연다. 기존 imagegen 중간 포즈 생성 규칙을 이 제작 방식으로 대체한다.

이 결정은 제작 난도와 자산 준비 비용을 늘린다. 대신 형태·조명·배율의 일관성을 원본에서 제어할 수 있으며 공개 실행에 3D 엔진이나 영상 재생을 추가하지 않는다. 실제 자연스러움은 단독 샘플을 검증해 판단한다.
