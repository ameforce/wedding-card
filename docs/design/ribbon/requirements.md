# 리본 개봉 요구사항

목표는 같은 리본의 끝단이 당겨지고 고리가 줄어들어 매듭이 풀린 뒤 청첩장이 열리는 연속 동작이다. 2026-09-05 사용자가 실제 풀림에 가까운 재현과 Blender에서 제작한 투명 연속 프레임 방식을 승인했다.

- 매듭, 고리, 꼬리, 가로 띠의 연결을 유지한다. 마지막 해제 상태에는 묶인 매듭이 남지 않는다.
- 프레임 사이 카메라, 배율, 캔버스와 기준점을 고정한다. 개별 바운딩박스 정규화와 반투명 포즈 교체를 사용하지 않는다.
- 리본이 완전히 퇴장한 다음 짧은 여백을 두고 종이를 연다.
- 공개 페이지를 새로 열 때마다 재생한다. `capture=1`과 Quiet에는 인트로를 마운트하지 않는다.
- 기존 공개 리비전 결정과 첫 화면을 보존한다. 실패와 건너뛰기는 본문 접근 및 스크롤을 복원한다.
- 실제 인물 사진, 초대 문구, 방명록, 관리자 API는 변경하지 않는다.
- 추가 비용 없이 직접 제작한다. 호환되는 무료 원본은 출처와 사용 조건을 보존하며 사용할 수 있다.

리본 단독 샘플의 정상·저속 재생에서 크기 튐, 천의 관통, 고리의 갑작스러운 생성·소멸, 이중 윤곽이 없어야 통합할 수 있다. 코드나 렌더 성공만으로 시각적 통과를 주장하지 않는다.

## 재제작의 추가 완료 조건

- 최초 HTML에는 묶인 표지와 필수 스타일이 있어야 한다. 메인 앱을 3초 늦추거나 프레임 요청을 막아도 빈 종이를 먼저 보여주지 않는다. 초기 표지와 재생 첫 프레임은 390px 화면에서 위치 차이가 1px 이하여야 한다.
- 준비 제한은 초기 표지 표시부터 5초다. 이는 준비 시간의 상한이며 정상 재생 전체의 제한 시간이 아니다. 준비가 끝나면 별도의 재생 감시로 인계하고 풀림·종이 개방을 중간에 잘라 종료하지 않는다.
- 천의 기준 형상을 고정하고 자유 끝단을 당겨 같은 재료가 매듭을 통과해야 한다. 실패한 물리 실험을 기존 고리 축소·직선화 동작으로 대체하지 않는다.
- 전체 하강은 완전 해제 뒤에만 적용한다. 마지막 가시 프레임은 실제 화면 하단보다 16px 이상 아래에 있어야 하며, 그 뒤 투명 종료 프레임과 종이 대기로 넘어간다.
- 종이 개방은 책의 양쪽 표지를 넘기듯 바깥 접힘선을 축으로 돌아가는 동작이다. 사용자가 지적한 평행 이동식 슬라이드는 채택하지 않는다. 원본에서 측정한 양쪽 안쪽 가장자리의 경로를 유지하면서 종이 무늬의 가로 압축, 좌우 명암 차이, 얇은 단면을 함께 표현한다. 중앙 틈을 통해 기존 본문이 점진적으로 드러나야 한다.
- 활성 화면의 정상 재생은 프레임 간격 95백분위 50ms 이내이며 100ms 초과 정지가 없어야 한다. 준비 중 실패와 재생 성공은 별개 시나리오로 판정한다.
- 사용자가 iPhone Chrome에서 리본 단독·전체 개봉 비교 샘플을 확인한 뒤에만 운영 배포한다. 실기기 미검증을 기능 테스트 결과로 대신하지 않는다.
